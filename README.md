# Villager Reroll

Reroll a librarian's trades without resetting the villager. For Fabric 1.21.11.

## Features

- Every trade in the villager's trading UI gets a square on the left: **green** = the trade gets rerolled, **red** = the trade is locked and stays as it is.
- On enchanted book trades with a multi-level enchantment, a second square appears on the right: **cyan** = nothing changes, **orange** = if the trade is locked, the enchantment stays and only its level and price are rerolled.
- A **Reroll** button below the window applies everything.
- Only the first two trades can be fully rerolled.
- Once you use one of the first two trades, the button and the squares are hidden.

## Install

1. Install Fabric Loader for Minecraft 1.21.11.
2. Download Fabric API for 1.21.11 and put it in your `mods` folder.
3. Download the `.jar` from the Releases page and put it in the same folder.
