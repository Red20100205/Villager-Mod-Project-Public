# Villager-Mod-Project-Public
Reroll a librarian's trades without resetting the villager. In the trading UI, each trade has a square: green = rerolled, red = locked. On enchanted books, a second orange square keeps the enchantment and rerolls only its level and price. A Reroll button applies it all. Controls hide after the first purchase. For Fabric 1.21.11.
